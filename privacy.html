한눈에 보기

  • 타닥타닥은 계정, 닉네임, 타자 연습 기록, 직접 쓴 글, 신고·피드백, 구매·광고 관련 정보를 서비스 운영에 필요한 범위에서 처리합니다.
  • 소셜 로그인(Google, Apple, Kakao)에서 받은 실명과 프로필 사진은 서비스 프로필에 저장하지 않으며, 앱에서는 이용자가 정한 닉네임만 사용합니다. 다만 Google·Kakao가 로그인할 때 보내는 이름·사진 주소는 인증 시스템(Supabase Auth)의 로그인 기록에 보관될 수 있습니다(1-1 참고).
  • AI 글쓰기 기능을 쓰면 이용자가 고르거나 입력한 주제·상황 설명이 연습 글 생성을 위해 OpenAI로 전송됩니다. OpenAI의 API 데이터 정책상 별도로 데이터 공유에 동의하지 않는 한 API 데이터는 모델 학습에 사용되지 않습니다.
  • 모두의 공간 공개 글은 OpenAI로 유해성 검사를 하며, 푸시 알림과 설치 후 친구 챌린지 초대 복원을 위해 필요한 정보를 처리합니다.
  • Supabase(서버·데이터 저장), Firebase Analytics·Crashlytics·Cloud Messaging(이용 분석·오류 보고·푸시 알림), Google AdMob(광고), Apple App Store·Google Play(결제), OpenAI(AI 글 생성·커뮤니티 유해성 검사)를 사용합니다.
  • 계정을 삭제하면 프로필, 기록, 작성 글 등 계정에 귀속된 데이터는 삭제되며, 일부 운영·결제 로그는 식별자를 제거한 형태로 남을 수 있습니다.

1. 처리하는 개인정보 항목

타닥타닥은 별도의 회원가입 입력 양식을 사용하지 않으며, 아래 정보는 소셜 로그인, 앱 이용 과정, 이용자의 직접 입력을 통해 수집됩니다.

1-1. 계정 및 로그인 정보

  • 내부 사용자 식별자(UUID), 게스트 여부, 로그인 상태
  • 소셜 로그인 제공자 정보: 제공자 이름(Google, Apple, Kakao), 제공자 사용자 식별자, 이메일 주소(제공된 경우)
  • 연동된 로그인 수단 목록과 마지막 로그인 제공자

서비스 프로필에 저장하지 않는 정보: 소셜 로그인 과정에서 제공자가 보내 줄 수 있는 실명(이름)과 프로필 사진은 타닥타닥 서비스 데이터(프로필)에 저장하지 않습니다. iOS의 Apple 로그인에서는 이름 제공을 요청하지 않습니다. 다만 Google·Kakao 로그인 시 제공자가 인증 토큰에 이름·사진 주소를 함께 담아 보내는 경우, 이 정보(이름, 프로필 사진 주소)가 인증 시스템(Supabase Auth)의 로그인 기록에 함께 보관됩니다. 이 정보는 앱 화면·랭킹·커뮤니티 등 서비스 기능에 사용하지 않으며, 계정을 삭제하면 함께 삭제됩니다.

1-2. 프로필 및 앱 설정

  • 닉네임, 닉네임 태그, 선호 테마, 글꼴, 글자 크기, 언어 설정

1-3. 타자 연습 및 학습 기록

  • 연습 기록(타수, 정확도, 연습 시간, 키보드 종류, 연습한 콘텐츠), 랭킹 점수, 연속 연습 기록, 미션·업적 달성 내역, 필사(성경 등) 진행 기록
  • 약점 분석 요약(자주 틀리는 자모·받침·띄어쓰기 유형과 오타율). 약점 분석은 기기 안에서 계산되며, 서버에는 요약 수치만 전송됩니다.

1-4. 이용자 콘텐츠

  • 직접 작성한 글의 제목, 본문, 작성자명, 언어, 공개 여부
  • AI 글쓰기로 만든 글(제목, 본문)과 저장 여부
  • 모두의 공간에 공개한 글, 공개/숨김 상태, 품질 점수, 신고 수, 운영 메모, AI 유해성 검사 판정(정상·검토·차단), 범주별 점수, 검사 시각
  • 좋아요, 가져오기, 공유 이력, 작성자 숨김/차단 목록

1-5. AI 글쓰기 입력 정보

  • 추천 주제 중 선택한 주제 또는 직접 입력한 주제
  • "나만의 실전 글" 입력: 상대와의 관계, 말투, 길이, 상황 설명, (메신저) 상대 호칭·이름(선택), (이메일) 받는 사람 이름·직함(선택), 목적
  • "약점 맞춤 글" 입력: 기기에서 계산한 약점 요약(유형, 오타율, 표본 수, 예시 단어). 이용자가 직접 친 문장 원문은 보내지 않습니다.
  • 입력 원문은 서버에 저장하지 않으며, 중복 요청 확인을 위한 해시값(원문을 알 수 없게 변환한 값)만 저장합니다.
  • 전화번호·이메일 주소·링크 등 연락처 형식의 입력은 받지 않습니다. 상황 설명에 실제 개인정보(실명, 연락처, 주소 등)를 적지 않도록 주의해 주세요.

1-6. 신고 및 피드백

  • 게시글 신고: 신고자 식별자, 대상 글 식별자, 신고 사유, 신고 시각
  • 사용자 신고: 신고자·대상자 식별자, 관련 글 식별자, 신고 사유, 신고 시각, 대상 스냅샷
  • 앱 내 피드백/버그 제보: 내용, 분류, 제출 경로, 플랫폼, 앱 버전, 제출 시각, 사용자 식별자(로그인한 경우)

1-7. 구매 및 이용권

  • 광고 제거·타닥 플러스(구독)·AI 생성권 상품 ID, 거래 식별자, 구매/복원/갱신/환불 상태, 스토어 오류 코드
  • 생성권(티켓) 지급·사용·소멸 내역, 보상형 광고 시청에 따른 지급 내역
  • 결제 수단(카드 번호 등)은 Apple·Google이 처리하며 타닥타닥은 받지 않습니다.

1-8. 광고 및 광고 식별자

  • 광고 노출·클릭·보상 지급 이벤트, 광고 지면 정보
  • 보상형 광고 검증(SSV): 서버가 발급한 일회용 토큰만 광고 사업자 콜백에 포함되며, 사용자 ID나 작성 글은 포함되지 않습니다.
  • iOS 앱 추적 투명성(ATT) 안내 노출 여부와 허용/거부 상태
  • 광고 식별자: iOS의 IDFA는 ATT에서 허용한 경우에만 Google AdMob이 맞춤형 광고와 광고 측정에 사용합니다. Android의 광고 ID는 기기의 광고 설정(광고 ID 삭제·재설정)에 따라 Google AdMob이 광고 제공과 측정에 사용합니다.
  • Google AdMob은 IP 주소로 추정한 대략적인 위치, 기기·성능 정보를 광고 제공 목적으로 처리할 수 있습니다.

1-9. 이용 분석 및 오류 정보

  • Firebase Analytics와 Supabase 이벤트 기록: 앱 실행, 세션, 연습 시작/완료, 기능 사용, 실험 노출, 광고·결제 이벤트
  • 설치 단위 익명 ID(anonymous_id), 사용자 ID, 세션 ID, 플랫폼, 앱 버전
  • Firebase Crashlytics 오류 보고: 오류 내용, 기기 종류, OS 버전, 앱 상태 정보, 사용자 ID를 해시(원래 값을 알 수 없게 변환)한 값

1-10. 푸시 알림

  • 기기 푸시 토큰(FCM/APNs를 통한 알림 전송에 사용하는 Firebase Cloud Messaging 토큰), 사용자 식별자, 플랫폼(iOS/Android), 앱 버전, 앱 언어(locale), 알림 활성화 상태, 토큰 등록·갱신 시각
  • "내 글 반응 알림" 수신 설정, 공개 글의 연습·좋아요·가져오기 반응 요약과 알림 발송 기록(날짜, 발송 처리·완료 시각)

1-11. 친구 챌린지 초대 복원

  • 앱 설치 전에 친구 챌린지 링크를 열면 설치 후 챌린지를 복원하기 위해 초대 기록 식별자, 챌린지 코드, 생성·복원 시각, 솔트(임의의 추가 값)를 적용해 해시한 IP 주소, 화면 너비·높이, 기기 픽셀 비율, 시간대, 언어, 플랫폼(iOS/Android), OS 주 버전(확인 가능한 경우)을 임시로 저장합니다. 이 초대 기록에는 IP 주소 원문, 사용자 에이전트 원문, 기기 고유 식별자를 저장하지 않습니다.

2. 개인정보 이용 목적

  • 회원 식별, 로그인 유지, 게스트/소셜 계정 전환 및 계정 연동
  • 타자 연습 기록 저장, 랭킹·미션·업적·필사 기록 제공
  • 개인 글 보관, 모두의 공간 공개/비공개 처리
  • AI 글쓰기: 이용자가 요청한 연습 글 생성, 입력·결과의 유해성 검사
  • 커뮤니티 공개 글의 AI 유해성 검사, 명백히 유해한 글의 자동 숨김, 경계 사례의 운영자 검토 대기열 등록, 계정 생성 시점·과거 신고 처리 결과·신고 활동에 따른 가중 신고 처리, 숨김/차단, 제재 검토, 정책 위반 방지
  • 푸시 알림 전송: 공개 글의 최근 24시간 연습·좋아요·가져오기 반응을 모아 매일 20:00(한국 표준시, KST)에 조건을 충족한 이용자에게 하루 최대 한 번 "내 글 반응 알림"을 보냅니다. 설정의 "내 글 반응 알림"에서 이 알림을 끄거나, OS 알림 설정에서 앱 알림을 끌 수 있습니다.
  • 친구 챌린지 링크를 앱 설치 후 복원하고, 중복 복원과 초대 기능의 부정 이용을 방지합니다.
  • 피드백 검토, 오류 대응, 고객 지원
  • 광고 제공, 보상형 광고 보상 지급, 구매·구독·복원·환불 처리
  • 서비스 이용 분석과 품질 개선(Firebase Analytics 데이터는 Google Ads와 연결하지 않으며 앱 개선 목적으로만 사용합니다)
  • 보안, 부정 이용 방지, 법령 준수, 분쟁 대응

3. 보유 기간 및 파기

3-1. 보유 기간

  • 계정, 프로필, 연습 기록, 작성 글, AI로 만든 글, 공개 글, 좋아요/가져오기, 숨김/차단 데이터는 계정을 유지하는 동안 보관하고 계정 삭제 시 삭제합니다.
  • 커뮤니티 유해성 검사 결과(판정·범주별 점수·검사 시각)는 게시글과 함께 보관하며 해당 게시글 삭제 시 함께 삭제합니다.
  • 푸시 토큰과 알림 발송 기록은 계정 삭제 시 삭제합니다. 앱 알림을 비활성화하면 해당 토큰은 비활성 상태로 보관하고 발송에 사용하지 않습니다. "내 글 반응 알림"만 끄면 해당 요약 알림만 중단됩니다.
  • 친구 챌린지 초대는 생성 후 60분 이내에 한 번 복원할 수 있습니다. 생성 후 24시간이 지난 초대 기록은 새 초대 기록·복원 요청 처리 시 삭제합니다.
  • AI 글쓰기 입력 원문은 서버에 저장하지 않습니다. OpenAI 측 보관 기준은 4절을 참고해 주세요.
  • 게시글 신고는 계정 삭제 시 삭제하며, 사용자 신고는 운영 검토 이력 보존을 위해 신고자/대상자 식별자를 제거한 상태로 남을 수 있습니다.
  • 피드백, 분석·광고·결제 이벤트 로그는 서비스 개선, 부정 이용 방지, 결제 지원을 위해 계정 식별자를 제거하거나 일부 마스킹한 형태로 수집일로부터 1년간 보관한 뒤 파기합니다. 다만 법령상 보관 의무가 있는 결제 관련 기록은 아래 기간을 따릅니다.
  • 구매·구독·환불 기록은 「전자상거래 등에서의 소비자보호에 관한 법률」에 따라 다음 기간 동안 보관합니다: 계약 또는 청약철회 등에 관한 기록 5년, 대금 결제 및 재화 등의 공급에 관한 기록 5년, 소비자 불만 또는 분쟁 처리에 관한 기록 3년.
  • 피드백 본문이나 신고 사유에 직접 입력한 내용은 제출 당시 문구 그대로 보관될 수 있으므로 민감한 정보를 적지 마세요.

3-2. 파기 절차 및 방법

  • 보유 기간이 끝났거나 처리 목적을 달성한 개인정보는 지체 없이 파기합니다. 관계 법령에 따라 보관해야 하는 정보는 다른 데이터와 분리해 해당 기간 동안 보관한 뒤 파기합니다.
  • 전자적 파일 형태의 정보는 복구할 수 없는 방법으로 삭제하며, 종이 문서로 된 개인정보는 처리하지 않습니다.

4. 개인정보 처리위탁 및 국외 이전

OpenAI 이용에 관한 안내

  • 이용자가 AI 글쓰기에서 고른 주제나 직접 입력한 상황 설명(관계, 말투, 길이, 선택 입력한 호칭·받는 사람 이름 포함)과 약점 요약이 연습 글을 만들기 위해 OpenAI API로 전송됩니다.
  • AI 글쓰기 입력 내용과 생성된 글은 OpenAI 모더레이션 API로 유해성 검사를 거치며, 기준을 넘으면 글을 만들지 않거나 보여 주지 않습니다.
  • 모두의 공간 공개 글은 제목·본문·작가명·게시자 닉네임을 OpenAI의 Moderation API와 분류 API로 전송해 검사합니다. 명백히 유해한 글은 자동으로 숨기고, 경계 사례는 운영자 검토 대기열에 올립니다. 판정과 범주별 점수는 게시글과 함께 저장합니다.
  • AI 글쓰기 요청에는 사용자 ID·이메일·닉네임을 별도 항목으로 보내지 않습니다. 커뮤니티 검사에는 위 공개 글 정보가 포함됩니다.
  • OpenAI의 API 데이터 정책에 따르면 별도로 데이터 공유에 동의하지 않는 한 API로 보낸 데이터는 OpenAI 모델 학습에 사용되지 않습니다.
  • AI 글 생성 요청에는 응답 저장 기능을 끕니다(store: false). OpenAI 정책상 Moderation API는 입력·출력을 보관하지 않으며, 글 생성·분류 API의 오남용 감시 로그는 기본적으로 최대 30일 보관될 수 있습니다. 법적 의무 또는 서비스·제3자 위해 방지를 위해 필요한 경우 더 오래 보관될 수 있습니다.
  • 매일 제공되는 "오늘의 글"과 공용 추천 주제는 이용자 정보 없이 서버가 OpenAI로 만든 공용 콘텐츠입니다.

5. 광고 식별자 및 ATT 안내

  • 타닥타닥 앱은 웹 쿠키를 사용하지 않습니다. 대신 위에서 설명한 광고 식별자와 설치 단위 익명 ID 같은 앱 식별 정보가 광고·분석 목적으로 쓰일 수 있습니다.
  • iOS에서는 앱 추적 투명성(ATT) 권한 요청 전에 안내 화면을 보여 줄 수 있으며, 안내 노출 여부와 허용/거부 결과를 기록합니다.
  • ATT를 허용하면 Google AdMob이 광고 식별자(IDFA)를 맞춤형 광고와 광고 성과 측정에 사용합니다. 이는 Apple 기준의 "추적"에 해당합니다.
  • ATT를 거부해도 광고는 표시될 수 있으며, 이 경우 광고 식별자 없이 제공됩니다. 설정은 iOS 설정 > 개인정보 보호 및 보안 > 추적에서 언제든 바꿀 수 있습니다. Android에서는 기기의 설정 > 개인정보 보호(또는 Google) > 광고에서 광고 ID를 삭제하거나 재설정할 수 있습니다.
  • Firebase Analytics 데이터는 Google Ads와 연결하지 않으며 광고 목적으로 사용하지 않습니다.
  • 광고 제거를 구매하거나 타닥 플러스를 이용하면 앱 안 광고 노출이 제한될 수 있습니다.
